# nuxt-page-composer

Nuxt module for [Page Composer](https://github.com/virgilvox/vue-page-composer). Registers the renderer globally, exposes `usePageComposer()` for loading and resolving documents, handles the SSR path so a page renders fully on the server and hydrates without mismatch, and offers an optional catch-all route that maps an incoming path to a stored document.

> Status: early development. This release reserves the package name. The module is landing in upcoming versions. Follow the repository for progress.
